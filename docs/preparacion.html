Preparación previa

Guía de preparación del entorno

Para realizar la sesión solo necesitas tener instalado Visual Studio Code, contar con una cuenta de GitHub y crear tu repositorio a partir de la plantilla oficial (SolvenzaIA/IA-masterclass). El resto de herramientas (Google Antigravity, Groq y OpenRouter) son alternativas opcionales que veremos durante el taller.

00

Requisitos previos

Identifica claramente qué necesitas tener listo de forma obligatoria y qué alternativas opcionales tienes a tu disposición:

Paso Obligatorio Crear tu repositorio a partir de la plantilla oficial

Sigue estos 4 pasos para tener tu propia copia del proyecto en tu cuenta de GitHub y abrirla en tu editor:

Paso Acción Instrucción y detalles
01 Abrir la plantilla Accede al repositorio oficial de la masterclass en GitHub: https://github.com/SolvenzaIA/IA-masterclass.
02 Usar como plantilla Haz clic en el botón verde superior «Use this template» (Usar esta plantilla) y selecciona «Create a new repository».
03 Crear tu repositorio Asigna un nombre a tu nuevo repositorio (ej. mi-portfolio-ia), déjalo marcado como Public (Público) y pulsa en «Create repository».
04 Abrir en VS Code En tu nuevo repositorio de GitHub, pulsa en el botón verde «Code» para clonarlo con Git en tu ordenador, o pulsa en «Download ZIP», descomprímelo y abre la carpeta con Visual Studio Code.
Nota de clase Cómo enfocar esta preparación

Con tener VS Code instalado, tu cuenta de GitHub y la plantilla abierta en tu editor ya podrás seguir y realizar todo el taller práctico con GitHub Copilot. Los pasos de Google Antigravity, Groq, OpenRouter y Continue te permitirán disponer de bolsas extra de tokens y probar más modelos de IA sin coste, pero son 100% opcionales y los veremos en directo.

01

Configurar GitHub Copilot en VS Code

GitHub Copilot es el asistente oficial de desarrollo integrado en el editor.

Fase A Instalar la extensión oficial

Paso Acción Instrucción y detalles
01 Abrir editor Inicia Visual Studio Code en tu ordenador.
02 Abrir Extensiones Pulsa el atajo Ctrl + Shift + X (en Mac: Cmd + Shift + X).
03 Buscar Copilot En la barra de búsqueda superior introduce: GitHub Copilot.
04 Instalar extensión Haz clic en el botón azul Install sobre la extensión oficial provista por GitHub.

Fase B Iniciar sesión con tu cuenta de GitHub

Paso Acción Instrucción y detalles
01 Iniciar vinculación En la esquina inferior izquierda del editor, pulsa en el icono de Cuentas o en la notificación Sign in to GitHub.
02 Autorizar en navegador Se abrirá el navegador; autoriza la vinculación con tu usuario de GitHub.
03 Comprobar activación Al regresar a VS Code, el icono del chat de Copilot quedará disponible en tu barra lateral izquierda.
02

Descargar e instalar Google Antigravity IDE (Recomendado · Gemini 3.8 Flash)

Paso recomendado: Google Antigravity es el nuevo IDE de desarrollo potenciado por agentes de Google. A diferencia de extensiones tradicionales, aquí no utilizaremos claves API (ya que Gemini no cuenta con CLI ni integración fluida en tier gratuito para herramientas externas); Gemini 3.8 Flash funciona de forma nativa dentro de la propia aplicación.

Paso Acción Instrucción y detalles
01 Descargar el IDE Entra en la web oficial antigravity.google y descarga el instalador de Google Antigravity para tu sistema operativo (Mac, Windows o Linux).
02 Instalar la aplicación Ejecuta el archivo descargado e instala el IDE en tu ordenador siguiendo las instrucciones habituales.
03 Iniciar sesión con Google Abre Antigravity e inicia sesión directamente con tu cuenta personal de Google / Gmail.
04 Listo sin claves API ¡Todo preparado! Gemini 3.8 Flash estará disponible de forma nativa e integrada en el editor para generar código y razonar con agentes durante la masterclass.
03

Obtener claves API: Groq y OpenRouter (Opcional)

Si quieres probar modelos de código abiertos dentro de la extensión Continue, puedes generar claves gratuitas en estos dos proveedores:

Vía A Groq Cloud (Modelos ultrarrápidos como Qwen)

Paso Acción Instrucción y detalles
01 Acceder al portal Entra en console.groq.com y crea una cuenta con Google o GitHub.
02 Crear y copiar clave Accede a https://console.groq.com/keys, pulsa en «Create API Key» y copia la clave generada (empieza por gsk_...).

Vía B OpenRouter (Acceso multimodelo y modelos free)

Paso Acción Instrucción y detalles
01 Acceder al portal Entra en openrouter.ai y pulsa en Sign In / Sign Up.
02 Crear y copiar clave Ve a openrouter.ai/settings/keys, pulsa en «Create Key» y copia la clave generada (empieza por sk-or-v1-...).
Seguridad Protege siempre tus claves privadas

Tus API Keys son personales. Nunca las subas a GitHub, no las compartas en chats públicos y nunca las pegues en archivos de código de tu proyecto. Guárdalas solo en el archivo .env de tu proyecto (copia .env.example y renómbralo): Git lo ignora y nunca se subirá.

04

Instalar y configurar Continue (Opcional)

Si prefieres quedarte en VS Code pero quieres probar modelos de código abiertos como Qwen o Nemotron, puedes instalar la extensión Continue.

Fase A Instalar la extensión Continue

Paso Acción Instrucción y detalles
01 Abrir Extensiones En VS Code, abre la pestaña de Extensiones con Ctrl/Cmd + Shift + X.
02 Instalar Continue Busca Continue (de Continue / Continue.continue) y haz clic en Install.
03 Abrir panel Haz clic en el icono de Continue en la barra izquierda o abre el chat con el atajo Ctrl + L (Mac: Cmd + L).

Fase B · Recomendado Configuración rápida mediante archivo config.yaml

En lugar de añadir los modelos de uno en uno, puedes pegar directamente la configuración completa en tu archivo config.yaml de Continue:

Paso Acción Instrucción y detalles
01 Abrir configuración En el panel de Continue, pulsa el icono de configuración (la rueda dentada) o presiona Ctrl/Cmd + Shift + P y escribe Continue: Open config.yaml.
02 Pegar configuración Copia el siguiente bloque y pégalo en tu archivo config.yaml.
03 Poner tus claves en .env No pegues claves en el YAML. En la raíz del proyecto, duplica .env.example como .env y rellena GROQ_API_KEY y OPENROUTER_API_KEY. Continue las lee automáticamente gracias a ${{ secrets.NOMBRE }}. Una sola clave de OpenRouter sirve para todos sus modelos.
YAML ~/.continue/config.yaml 
name: Main Config
version: 1.0.0
schema: v1
models:
  - name: qwen/qwen3.8-27b
    provider: groq
    model: qwen/qwen3.8-27b
    apiKey: ${{ secrets.GROQ_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply

  # Razonamiento y agentes complejos
  - name: Nemotron 3 Ultra - Free
    provider: openrouter
    model: nvidia/nemotron-3-ultra-550b-a55b:free
    apiBase: https://openrouter.ai/api/v1
    apiKey: ${{ secrets.OPENROUTER_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use

  # Especializado en desarrollo de software
  - name: North Mini Code - Free
    provider: openrouter
    model: cohere/north-mini-code:free
    apiBase: https://openrouter.ai/api/v1
    apiKey: ${{ secrets.OPENROUTER_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use

  # Bugs, tests y funcionalidades
  - name: Flint - Free
    provider: openrouter
    model: recursive/flint-v1.0:free
    apiBase: https://openrouter.ai/api/v1
    apiKey: ${{ secrets.OPENROUTER_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use

  # Análisis multimodal de interfaces
  - name: Nemotron Super VL - Free
    provider: openrouter
    model: nvidia/nemotron-3.5-super-vl:free
    apiBase: https://openrouter.ai/api/v1
    apiKey: ${{ secrets.OPENROUTER_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use
      - image_input

  # Modelo ligero para tareas rápidas
  - name: Nemotron Lightning - Free
    provider: openrouter
    model: nvidia/nemotron-3.5-lightning:free
    apiBase: https://openrouter.ai/api/v1
    apiKey: ${{ secrets.OPENROUTER_API_KEY }}  # Se lee de tu archivo .env
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use
context:
  - provider: code
  - provider: docs
  - provider: diff
  - provider: terminal
  - provider: problems
  - provider: folder
  - provider: codebase

Fase C · Alternativa Configuración visual paso a paso (asistente)

Si prefieres no editar el archivo config.yaml, puedes añadir los modelos desde los desplegables de Continue:

Paso Acción Instrucción y detalles
01 Añadir Qwen (Groq) En el selector inferior de modelo de Continue pulsa + Add Chat model ➔ elige proveedor Groq ➔ indica el modelo qwen/qwen3.8-27b ➔ pega tu API Key de Groq.
02 Añadir Modelo Free (OpenRouter) Pulsa de nuevo + Add Chat model ➔ elige proveedor OpenRouter ➔ indica un modelo libre como cohere/north-mini-code:free ➔ pega tu API Key de OpenRouter.
03 Alternar en el chat ¡Listo! Podrás alternar entre Qwen en Groq y los modelos free de OpenRouter desde el desplegable en cualquier momento de la sesión.
